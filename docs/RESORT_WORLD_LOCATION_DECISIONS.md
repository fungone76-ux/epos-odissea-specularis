# RESORT WORLD — LOCATION DECISIONS

Documento complementare a `RESORT_WORLD_DESIGN_V1.md` per consolidare progressivamente le decisioni sulle location e sui relativi prompt ambientali.

## Regola generale

- Il resort è mediterraneo moderno e tutte le location devono trasmettere lusso ed esclusività.
- La descrizione narrativa dell'ambiente resta libera per il giocatore e per la narrazione.
- I prompt visivi devono usare soltanto 2 o 3 tag ambientali distintivi per non diluire identità, outfit, posa e azione del personaggio.
- Le zone interne non diventano automaticamente location separate: possono essere indicate liberamente nella scena e usare un tag specifico sostitutivo o aggiuntivo.

## Location confermate

### Suite presidenziale

Una sola location con zone narrative interne: ingresso privato, salotto, camera, bagno di lusso, cabina armadio e terrazza vista mare.

Tag canonici:

```text
modern mediterranean luxury suite, warm elegant interior, sea-view windows
```

### Lobby

Grande, luminosa e lussuosa.

Tag canonici:

```text
luxury resort lobby, marble reception, sea-view glass hall
```

### Ristorante

Ristorante elegante vista mare, con servizio raffinato.

Tag canonici:

```text
luxury seaside restaurant, elegant dining room, ocean-view terrace
```

### Piscina

Una sola location con possibilità narrativa di descrivere liberamente area principale e zona VIP, senza suddividerle nella mappa.

Tag canonici:

```text
luxury infinity pool, mediterranean resort deck, panoramic sea view
```

### Spa

Una sola location comprendente come zone narrative interne:

- sauna;
- bagno turco;
- sale massaggi;
- area benessere principale.

Tag canonici:

```text
luxury hotel spa, marble wellness area, soft ambient lighting
```

Queste zone restano liberamente descrivibili dal giocatore e non consumano ulteriori slot della mappa.
